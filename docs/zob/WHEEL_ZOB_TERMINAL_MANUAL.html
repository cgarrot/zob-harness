A SAFE FIRST SESSION

Your first 10 minutes

Start with a goal, make the work visible, delegate only bounded tasks, and close with evidence. ZOB should reduce ambiguity—not hide it.

Choose the operating mode

Use the mode that matches the next action. Mode changes tools and guardrails; it does not grant authority.

/zmode explore

Bind one concrete goal

Name the outcome and constraints. A goal gives the status widget and TODO tree one source of truth.

/goal Create a reviewed draft PR; do not merge

Break it into observable work

Use TODOs for parent-owned acceptance. Child claims are not completion until reviewed and accepted.

/todo Add integration evidence

Inspect before delegating

Discover the agent and output contract first. Bounded paths and explicit stop conditions prevent authority creep.

/agents

Watch truth, not activity theater

Heartbeat means connected. Progress means accepted state change. Review and Quality expose unresolved gates.

/zstatus

Use governed Git only when asked

ZOB can plan a commit. Commit or push occurs only after explicit authorization through the governed path.

/zcommit

CURRENT CORE VS APPROVED DESIGN

What a complete Wheel run will look like

These factory boundaries are binding design contracts, not claims of activation. Current ZOB mechanisms can support bounded goals, agents, evidence and review; the Wheel-specific GitHub Apps, branches and automatic transitions remain disabled.

Story → PR-Close

Build, docs, QA and exact-head close evidence. Stops at a draft PR and review handoff.

Specified
Blind Review

Fresh read-only review. Findings return to a separate repair attempt; a clean result cannot merge.

Disabled
Staging Merge

Qualified ordinary PRs auto-ready and squash-merge one at a time into non-deploying develop-staging.

Disabled
Repository Assurance

Human-started freeze, ten independent lanes, separate repair PR, fresh full re-audit; maximum three rounds.

Disabled
Promotion

Distinct human authorization binds the final exact candidate. Promotion uses merge-commit into develop.

Disabled
Automatic CD

May run only from the audited develop promotion push. ZOB never manually dispatches deployment.

Not configured

EVIDENCE-BACKED ROUTING

Models & Testing

Provider/model pools are no longer a deferred placeholder. A gated capability audit (2026-07-18) tested 20 routes with 297 real inference calls and $0.13 metered spend against a $5 cap. Only routes that passed their required capabilities on the actual provider path enter pools. Registration alone was never a pass.

Verified providers

Provider surface

  • Fireworks via Fireconnect CLI v0.8.0 — OpenAI-compatible endpoint, API key in OS keychain, Pi [on]. 17 verified routes.
  • OpenAI Codex — built-in Codex OAuth, 3 verified gpt-5.6 routes.
  • Fireconnect is a setup/proxy tool, not a separate provider. No credential or base URL stored in this repository.
Audit facts

What was tested

  • 11-test battery per Fireworks route: inference, roles, JSON, tool-calls, tool continuation, streaming, thinking low/high, context, cancellation, quality fixture.
  • Reduced battery for OpenAI (pi CLI wraps JSON/tool/streaming).
  • Thinking format auto-detection: budget_tokens vs reasoning_effort enum.
  • Role-format fallback: qwen rejects developer, uses system+user.

Role pools

Fixed/stable roles run on openai-codex/gpt-5.6-sol at high thinking. Randomized pools are shuffled per mission with a cryptographic model-order seed.

Select a pool to see its verified routes, families, thinking formats and costs.

Thinking format adapter

ZOB routing must apply the correct thinking control per model family. An unapproved clamp is a capability mismatch, not a successful rung.

FormatModelsDifferentiates output?
reasoning_effort enumgpt-oss-120b, minimax-m2p7✓ yes (e.g. 135→510 tokens)
budget_tokenskimi, deepseek, minimax-m3, nemotron✓ yes
budget_tokens advisoryglm, qwen⚠ accepted but no visible clamp at fixture size

Findings & caveats

Resolved

  • gpt-oss-120b thinking fixed: uses reasoning_effort enum, not token budget. Great coder, thinking differentiates, fast (1.7s), cheap ($0.15/$0.60).
  • qwen roles fixed: system+user only; all other capabilities pass.
  • Sol-high resolved: openai-codex/gpt-5.6-sol at high thinking for all fixed roles.

Unverified / out of scope

  • OpenAI JSON mode / raw tool-call format / streaming event order (pi CLI wraps these).
  • GLM/qwen thinking budget clamping at larger fixture sizes (advisory at fixture scope).
  • Encrypted transcript/redaction posture (out of scope for fixture testing).
  • nemotron-3-ultra: passes all tests but ~20s latency — ad-hoc only, not for throughput pools.

AUTHORITY IS EXPLICIT

What ZOB can—and cannot—decide

Presence, activity, a model response, a label or a comment never becomes authority by itself. The parent, oracle and human each own different decisions.
